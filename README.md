## 💻 รายวิชาที่เรียน: Backend Development

การเรียนรู้เกี่ยวกับการพัฒนาฝั่งเซิร์ฟเวอร์ (Backend) เพื่อจัดการกับฐานข้อมูล, Logic ของระบบ และการสร้าง API เพื่อเชื่อมต่อกับฝั่งหน้าบ้าน (Frontend)

### 📚 หัวข้อหลักที่ศึกษา
1. **พื้นฐานการทำงานของ Server:** เข้าใจสถาปัตยกรรม Client-Server และ HTTP Methods (`GET`, `POST`, `PUT`, `DELETE`)
2. **การจัดการฐานข้อมูล (Database):** การออกแบบและเชื่อมต่อฐานข้อมูลเพื่อเก็บข้อมูลอย่างปลอดภัย
3. **การสร้าง API:** การสร้าง RESTful API เพื่อส่งต่อข้อมูลในรูปแบบ JSON

### 📝 หัวข้อย่อยที่น่าสนใจ
* การใช้งาน **Node.js** และ **Express Framework**
* การจัดการ routing และ Middleware
* การตรวจสอบสิทธิ์และความปลอดภัย (Authentication & Authorization)
* การจัดการและควบคุมข้อผิดพลาดของระบบ (Error Handling)

## 🛠️ ตัวอย่างการเขียน Code ด้วย Node.js

นี่คือตัวอย่างการสร้าง Web Server อย่างง่ายด้วย **Node.js** และ **Express** เพื่อสร้าง API สำหรับตอบกลับข้อความ

```javascript
// 1. นำเข้าโมดูล Express
const express = require('express');
const app = express();
const PORT = 3000;

// เคลียร์ให้ระบบรองรับข้อมูลแบบ JSON
app.use(express.json());

// 2. สร้าง Route สำหรับหน้าแรก (Main Endpoint)
app.get('/', (req, res) => {
    res.json({
        message: "ยินดีต้อนรับเข้าสู่ Backend API ของฉัน!",
        status: "Success",
        college: "วิทยาลัยพณิชยการบางนา"
    });
});

// 3. สร้าง Route สำหรับรับข้อมูล (Post Endpoint)
app.post('/api/user', (req, res) => {
    const { name, major } = req.body;
    res.status(201).json({
        message: "บันทึกข้อมูลนักศึกษาเรียบร้อยแล้ว",
        data: { name, major }
    });
});

// 4. สั่งให้ Server รันที่ Port ที่กำหนด
app.listen(PORT, () => {
    console.log(`Server กำลังรันอยู่ที่ http://localhost:${PORT}`);
});
